## 어떤 길을 선택하면 되나요?

| 내 환경 | 따라갈 섹션 |
|---|---|
| Windows 사용자 | Windows 설치 |
| Mac 사용자 | Mac 설치 |
| 이미 설치했는데 업데이트하고 싶음 | 업데이트 |
| 설치 중 막힘 | 막혔을 때 |

Windows 사용자는 Scoop 경로를 권장합니다. 다른 분께 안내하거나 화면 공유를 받을 때도 이
경로가 가장 설명하기 쉽습니다.
