## 4. 첫 상태 확인

프로젝트 루트에서 실행합니다.

```bash
sfs status
```

처음에는 아래처럼 sprint 가 비어 있을 수 있습니다.

```text
sprint - · WU - · gate -:- · ahead 0 · last_event -
```

대시는 "아직 시작한 sprint 가 없다"는 뜻입니다.
